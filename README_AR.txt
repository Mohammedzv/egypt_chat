EGYPT CHAT — تسجيل بالبريد والاسم + يوزر فريد

المميزات:
- إنشاء حساب باسم العرض + يوزر مميز + بريد إلكتروني + كلمة مرور.
- تسجيل الدخول بالبريد وكلمة المرور.
- لكل مستخدم يوزر فريد مثل @mohammed_23.
- البحث عن أي مستخدم وبدء محادثة بكتابة اليوزر فقط؛ لا يحتاج الباحث إلى رقم هاتف أو بريد الشخص.
- محادثات خاصة ورسائل لحظية.
- إنشاء مجموعة (في النسخة الحالية منشئ المجموعة فقط عضو فيها).
- تعديل اسم العرض.

إعداد Firebase:
1. Authentication > Sign-in method > فعّل Email/Password.
2. Authentication > Settings > Authorized domains: أضف دومين GitHub Pages.
3. افتح Realtime Database > Rules وانسخ database.rules.json كاملًا ثم Publish.
4. تحقق أن databaseURL في firebase-config.js هو رابط قاعدة البيانات الفعلي لمشروعك.
5. ارفع جميع الملفات على GitHub Pages.

ملاحظات مهمة:
- اسم المستخدم فريد وغير قابل للتغيير من الواجهة في هذه النسخة.
- اسم المستخدم يقبل 3-20 حرفًا: حروف إنجليزية وأرقام وشرطة سفلية ونقطة.
- البحث عن المستخدمين يتم باليوزر فقط؛ البريد لا يظهر للآخرين في شاشة البحث.
- لا تستخدم قواعد عامة مفتوحة للقراءة والكتابة.
- هذه نسخة أولية: لا تدعم بعد دعوة أعضاء المجموعات أو إرسال الصور والصوت أو إشعارات Push أو التشفير الطرفي.
- اختبر بحسابين منفصلين قبل الاستخدام العام.
