EGYPT CHAT — النسخة الأولى

الموجود حاليًا:
- تسجيل دخول برقم الهاتف وكود OTP عبر Firebase Authentication.
- إنشاء ملف مستخدم تلقائيًا.
- تعديل اسم المستخدم.
- البحث عن مستخدم برقم الهاتف عبر فهرس أرقام الهاتف وبدء محادثة خاصة.
- محادثات مباشرة وتحديث الرسائل لحظيًا.
- إنشاء مجموعة (النسخة الحالية تنشئ المجموعة وتضيف منشئها فقط).
- واجهة عربية متجاوبة للموبايل والكمبيوتر.

قبل التشغيل:
1) افتح Firebase Console للمشروع egypt-956e1.
2) Authentication > Sign-in method > فعّل Phone.
3) Authentication > Settings > Authorized domains: أضف localhost أو دومين الاستضافة.
4) Realtime Database: أنشئ قاعدة بيانات. راجع database.rules.json وانشر القواعد.
5) إذا كان رابط قاعدة البيانات مختلفًا عن الرابط الموجود، عدّل databaseURL في firebase-config.js.
6) شغّل المشروع عبر خادم محلي أو ارفعه إلى استضافة HTTPS. لا تفتح index.html مباشرة من مدير الملفات.

مهم:
- مفتاح apiKey الظاهر في إعدادات Firebase للويب ليس كلمة مرور؛ حماية البيانات تعتمد على Authentication وقواعد قاعدة البيانات.
- لا تستخدم قواعد عامة تسمح بالقراءة والكتابة للجميع.
- Firebase Phone Auth قد يتطلب تفعيل الفوترة/قيود SMS حسب البلد والاستخدام، وقد تحتاج إعدادات مكافحة إساءة الاستخدام.
- المجموعة حاليًا لا تدعم إضافة أعضاء من الواجهة بعد الإنشاء.
- لا يوجد حتى الآن إرسال صور/صوت أو إشعارات Push أو تشفير طرف لطرف؛ هذه مراحل تطوير لاحقة.
- لا تعتبر المشروع جاهزًا للإطلاق العام قبل اختبار القواعد وتدفق OTP على أكثر من حساب وجهاز.

تحديث إصلاح تسجيل الدخول:
- تم دعم إدخال الرقم المصري المحلي 01xxxxxxxxx وتحويله تلقائيًا إلى +201xxxxxxxxx.
- تم تحسين إعادة تهيئة reCAPTCHA بعد فشل الإرسال.
- تظهر الآن تفاصيل Firebase ورمز الخطأ الحقيقي على الشاشة وفي Console بدل إظهار رسالة عامة فقط.
- إذا ظهر auth/operation-not-allowed رغم تفعيل Phone، راجع أن Firebase Config يعود لنفس مشروع Firebase الذي فعّلت فيه Phone، ثم أعد نشر الملفات.
