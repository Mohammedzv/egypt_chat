EGYPT CHAT - دليل التشغيل
=========================

المحتويات:
- index.html       واجهة التطبيق
- style.css        التصميم المتجاوب
- app.js           تسجيل الدخول والمحادثات والبحث
- firebase-config.js إعدادات مشروع Firebase
- database.rules.json قواعد Realtime Database

قبل التشغيل:
1) افتح Firebase Console للمشروع egypt-956e1.
2) من Authentication > Sign-in method فعّل Email/Password.
3) من Realtime Database أنشئ قاعدة بيانات إن لم تكن موجودة.
4) انسخ رابط قاعدة البيانات الظاهر أعلى صفحة Realtime Database.
5) افتح firebase-config.js وتأكد أن databaseURL يطابق الرابط حرفيًا.
6) من Realtime Database > Rules الصق محتوى database.rules.json ثم اضغط Publish.
7) شغّل الموقع من استضافة تدعم HTTPS و ES Modules مثل Firebase Hosting أو GitHub Pages.
   لا تفتح index.html مباشرة من مدير الملفات لأن المتصفح قد يمنع تحميل وحدات JavaScript.

طريقة النشر السريعة:
- ارفع الملفات الستة إلى مستودع GitHub.
- فعّل GitHub Pages من Settings > Pages.
- انتظر رابط الموقع ثم افتحه.

الخصائص الموجودة:
- إنشاء حساب بالبريد الإلكتروني وكلمة المرور واسم العرض.
- حجز يوزر فريد @username.
- البحث عن المستخدم باليوزر وبدء محادثة خاصة.
- رسائل نصية فورية.
- إنشاء مجموعات شخصية (منشئ المجموعة هو العضو الوحيد حاليًا).
- تعديل اسم العرض.
- واجهة عربية RTL متجاوبة.

ملاحظات مهمة:
- لا يوجد تسجيل برقم الهاتف ولا رسوم SMS.
- لا يتم نشر البريد الإلكتروني ضمن الملف العام للمستخدم.
- قواعد Firebase بداية عملية وليست تدقيقًا أمنيًا احترافيًا؛ اختبرها على مشروع تجريبي قبل إطلاق عام.
- ميزة دعوة أعضاء للمجموعات، الصور، المكالمات، الإشعارات، واستعادة كلمة المرور ليست ضمن هذه النسخة الأولى.
- اليوزر لا يمكن تغييره في هذه النسخة لتجنب كسر فهرس البحث وروابط المحادثات.


تحديث إصلاح المحادثات:
- استبدل قواعد Realtime Database بمحتوى database.rules.json الجديد ثم اضغط Publish.
- ارفع جميع ملفات النسخة الجديدة إلى الاستضافة مع استبدال app.js و database.rules.json.
- بعد إنشاء المحادثة يتم حفظ سجلها أولاً، ثم إضافتها لقائمة الطرفين؛ هذا الترتيب مطلوب لقواعد الصلاحيات.
- الرسائل نصية وفورية بين أعضاء المحادثة.
